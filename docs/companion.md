# 备忘与心绪

## 备忘从创建到消费

页面通过 `/v1/companion/memos`，AI 通过 MCP 的 `memo_create` / `memo_list` / `memo_update`（或等价 HTTP `/v1/extensions/{name}`），最终写入同一实例数据库的 `reminders` 表。不写 Scene/Event，不跑 embedding。

`memo_create` 可设标题、正文、开始/结束、重复、轮次间隔、每日/总次数上限和冷却分钟。默认每 6 轮、每天最多 1 次；早晚未指定每日上限时为 2 次。单次须明确选择 once。页面按用户要求不展示会话、“稍后”和“下次出现”；底层 next_due_at 由既有调度逻辑保留。

聊天 API 收到当前用户问题后，`chat_features.prepare` 取活动备忘，检查时间、状态、窗口/通道范围、每日/总次数、冷却及轮数，每次最多带入两条。上下文包含 memo_id、标题和正文。MCP 列表读取不消费提醒；打开页面也不消费。

只有上游返回包含正文、没有 tool_calls 的成功最终回复，才登记本轮已带入：reminder_count / daily_reminder_count 增加，更新最后提醒时间及内部下次时间。流式还必须收到完成标记且没有错误；中断或工具中间回复不消费。重试工具续轮沿用本轮收据，不重复计备忘次数。

“消费”表示备忘已进入这次成功模型调用，不保证 AI 在正文中提到了它，也不表示现实事项完成。要完成事项，页面点“标完成”，或 AI 明确调用 `memo_update(memo_id=..., status="done")`。once/none 消费一次自动归档；总次数耗尽、超过有效期也归档。每日/早晚按存储规则安排下次机会。这不是主动通知服务。

## 梦境读取与晨间注入

设置 → 功能中有两个独立开关，默认关闭。梦境生成仍使用配置页的梦境模型、每日概率与写作设定。

开启「梦境读取」后，MCP 和 HTTP 扩展提供 `dream_read`：默认读最新一篇，`index=2` 读倒数第二篇，`index="1,3,5"` 一次读多篇全文。开启窗影后，`window_shadow_read` 使用同一套参数。返回内容标明倒数第几篇，不列内部 ID；按真实生成／创建时间倒序排列，删除记录不占序号，新记录会使旧序号变化。每次最多选择 20 篇，序号范围 1～10000，重复序号只读一次，找不到的位置单独标明 not_found，不影响其他篇。

梦境读取不改变已带入状态，也不消耗晨间机会；窗影读取不写入画像。关闭梦境读取时不注册工具，公共 MCP 的 read_memory 也不能绕过开关读取梦境。醒来页面仍可阅读已有梦境。

开启「晨间梦境注入」后，按当前日期时间设置中的时区，每天凌晨四点后的第一条新用户消息，带入最近 24 小时内最新且尚未带入的梦。跨窗口共用一天一次的机会；四点前不带入。没有符合条件的梦时不添加内容，也不调用模型补梦，该消息成功回复后结束当天机会。梦境明确标为想象内容，不参与事实召回。

与备忘一样，只有成功的最终正文回复才登记已送达；失败、流式中断和工具中间回复不消费，重试与工具续轮复用原上下文。已带入的梦保留供页面和读取工具查看。此开关通过聊天网关生效；直接使用 MCP 不会主动推送晨间消息。

## 工具如何接到 AI

开关打开时，MCP 动态注册三个 memo 工具；关掉后 tools/list 不再返回，旧客户端缓存的 tools/call 也会被拒绝。页面管理 API 独立存在，关闭仍可整理备忘。

聊天代理转发客户端提供的 tools 和工具结果，不会自行执行模型返回的 function call。客户端/agent 需要连接 Serein MCP，或调用扩展 HTTP API 后把 tool result 续回同一聊天。仅在网页启用备忘不会自动替聊天客户端配置 MCP。

## 心绪（Persona）

设置中的 Persona 模型名由 TaskClient 解析当前实例模型目录，真正使用所选提供方、模型、密钥。聊天模型和 Persona 模型可以不同。关闭或没选模型时不调用 Persona 模型。

心绪与防撤退评估默认关闭模型思考：官方 DeepSeek、硅基流动和 DeepSeek Anthropic 协议分别使用各自支持的关闭参数；未知上游不发送未经声明的私有参数。这个设置不改变聊天主模型。

开启后，每个窗口独立累计成功最终回复轮数。每 3 轮，在回复完成后把本轮用户原话、AI 正文、最近完整问答、召回 IDs 交给评估器；工具续轮从缓存恢复原始问题，不把工具结果当作用户原话。评估更新全局关系与窗口情绪；符合原引擎事件筛选规则时保留变化记录。页面只读这些表，不手工调参。

心绪评估结果只保存为状态和变化记录，供心绪页面展示，不注入后续聊天。状态读取保留原衰减逻辑；失败评估写失败记录，不虚构状态变化。Persona 页面可见时每 15 秒读取一次最新结果，回到浏览器标签页时立即读取，保留手动刷新。防撤退是独立功能；只有它判断命中时，才按自己的冷却规则在下一轮带入一次提示。

心绪页展示内心的话与更新时间；情绪数值与关系基调放在可展开区域。心情记录按时间排为纸卡，点击卡边展开，用滚轮、前后按钮或键盘翻阅；长正文可在当前卡内滚动。支持减少动态效果。

新成功评估对应的最新纸卡轻轻落入顶部；正在读旧卡时保持当前页，提供查看新页入口。首次访问建立历史基线，不补播旧记录；离开期间的新记录下次访问仍会保留提示。只有卡片标题进入可视区域且动画完成后才确认已看，中途离开不消耗；失败不触发动画。减少动态效果时省略运动，在看到卡片时确认。已看标记存在本机浏览器 localStorage，按站点路径和所选窗口区分，不同步设备，不改变后端 Persona 数据。
