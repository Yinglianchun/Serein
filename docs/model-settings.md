名字点击“保存名字”后写入当前实例数据库。界面、作者角色显示、召回身份、Event 输入、梦境、

## 上游与模型列表

“模型”页管理上游、密钥和模型列表；“配置”页选择各功能使用的模型、自动摘要执行方式和参数。“功能”页保留自动摘要等开关。

按旧配置模板的 `gateway.upstreams` 结构配置：添加一个上游，填写名称、API Base URL、密钥或
`api_key_env`、协议与缓存选项，再在它下面添加多个模型。地址与密钥由该上游的全部模型共用。

通过 HTTP 地址（包括局域网 IP 和公网 IP 加端口）打开 Serein 网页时，也支持添加上游、手动添加模型和导入同名模型。旧版若点击“添加上游”没有反应，升级后刷新页面重试。这项兼容指网页访问方式，上游 API Base URL 仍按模型服务提供方的要求填写。公网明文 HTTP 会使登录凭据、提交的模型密钥和页面内容面临传输泄露风险；推荐使用 HTTPS 或加密隧道，风险提示不改变这些网页操作的兼容支持。详见 [HTTP 兼容与访问风险](interactive-install.md#http-兼容与访问风险)。
模型的 `id` 是稳定的内部编号，`upstream_model` 是发送给提供方的真实模型号，`label` 是可选别名。
客户端显示“上游名/别名”，别名留空就使用真实模型号。不同上游的同名模型由上游名区分，同一上游内需使用不同别名。旧内部编号继续支持请求路由。

填写上游地址后可点击“拉取模型”，搜索并勾选后“添加所选”，最后保存模型设置。
拉取只读取该上游的 `/models`，不会自动保存列表、改变任务选择或调用聊天模型。
密钥留空时沿用该上游已保存的密钥；地址改变后需要重新填写对应密钥。
新填写的密钥环境变量需先保存后使用。支持 OpenAI 与 Anthropic 的模型列表鉴权；
接口不支持、超时或返回空列表时仍可手动填写。每个上游最多保存 500 个模型。
同名模型跨上游添加时会生成独立内部编号，客户端不会显示这些 UUID。

聊天入口聚合已配置上游中的聊天模型，**排除已选为 Embedding 或 Reranker 的模型**，不需要在设置页选择一个聊天模型。客户端拉取模型列表，
每次请求指定其中的名字，就会路由到对应上游。Writer、Embedding、Reranker、Scene 关系、梦境、
叙事卷找材料、心绪、防撤退和 Event 整理的三个角色从生成模型列表中选择。向量和重排下拉框仍可选对应协议的全部模型。已保存的旧单模型按连接归入上游编辑器，保存后保留任务绑定、密钥及向量参数。

[可直接导入的模板](../examples/gateway-upstreams.example.yaml) 使用通用占位地址与环境变量名。
在“从配置模板导入”中粘贴修改后的 YAML / JSON，点击“导入并保存上游”；也可逐项填写表单后保存。
导入替换上游列表，不修改名字或其他功能选择；若要删除仍被任务选择的模型，应先清空对应选择。
支持模板中的模型字符串列表、别名映射、默认模型、密钥环境变量和缓存配置。此入口只导入
`gateway.upstreams`，不处理旧模板中的其他网关参数、人设和记忆配置。

密钥保存在实例数据库中，读取接口只返回“是否已配置”；留空保留密钥，显式勾选删除才清空。
数据库和所有运行目录不进入源码发行包。模型列表不是浏览器 localStorage 配置。

文本生成支持 Chat Completions 和 Anthropic Messages 上游，聊天客户端入口统一为 Chat Completions。
Embedding 使用 `/embeddings`，Reranker 使用 `/rerank`；选择相应用途的模型。
更换 embedding 后，先保存，再点击“建立 / 补齐检索索引”。它会探测维度，生成完整公开路由例句和正文（开启长文分段时还包括 passages）
向量，同时建立实体与 Arc 范围索引，为新模型创建独立可重建索引。成功后再开启“聊天时自动带入记忆”。
从旧版少量路由例句升级后，需要重新准备一次；实体与 Arc 不需要另填配置文件。见 [召回说明](recall.md)。

**什么时候按“建立 / 补齐检索索引”：** 首次配置、更换 Embedding，或页面提示规则资源需要重新准备时使用。先保存配置，按钮读取已保存的模型和 Passage 设置；日常新增、修改记忆由后台处理，不用每次按。首次给旧记忆开启 Passage 或确认存在历史缺失向量时，也可显式运行补齐。

**重复按会做什么：** 同一模型下复用当前有效的正文向量、已有分段及分段向量，只补缺失项，不重写正文、不全库重切。但仍重新请求维度探测、计算路由例句向量、扫描记忆覆盖并更新实体索引，有模型调用与服务器开销。换 Embedding 后使用新模型独立索引，正文和分段向量需重新生成；已保存的共享分段布局可复用，尚未补入共享布局库的历史分段不保证复用。已有空布局也保留，降低门槛后重复准备不会自动重切这些旧短文。准备期间暂时撤下就绪标记，失败需重试完成。当前后台不独立修复空队列之外的历史缺口，因此这个按钮也不是只补缺口的轻量刷新。

“配置 → 长文分段检索（Passage）”是独立可选开关，新实例默认关闭；旧实例显式配置的 TOML `recall.passages_enabled` 在页面保存前继续生效。可输入起切字数（1–100000 的整数，默认 500），有效正文**超过**该值才切段；汉字、字母和标点均按字符计，Scene 的评论等上下文段落不计入证据正文。门槛不是每段的长度；每段仍为最多 240 字符的原文窗口，保留原文位置，不改写记忆。
它帮助找回长 Event / Scene 中的具体细节，减少细节被整篇主题盖住的情况；当前独立日记和叙事卷不走这条检索通道。片段用于找到所属记忆，不拆成多条记忆，命中后仍受相关性筛选与冷却限制。长文较多、经常查询细节时可开启；短文为主可先关闭。分段向量会增加 Embedding 调用量、处理时间和索引占用。网页“使用说明 → 长文分段”提供例子与操作说明。
保存或首次导入记忆时先保存分段位置；分段不需要模型，分段向量由持久队列在后台补齐。后续只处理新增或修改的记忆，重复导入、只改标题和更换 Embedding 都复用已有正文分段。修改起切字数只应用于新正文，不自动全库重切；老记忆可在明确点击“建立 / 补齐检索索引”后补齐缺失分段，已准备的继续复用。
关闭后停止分段检索、分段向量生成和 cue 到分段的模型绑定，已有记忆和索引保留。聊天请求只读准备好的分段向量，不现场切段或补向量；缺失时仍走可用的整篇检索。`use_passages=true` 也不会越过实例关闭开关。

“配置 → 召回门槛”可分别调整正文向量扩展门槛（默认 0.50）、Scene cue 语义扩展门槛（默认 0.55）与最终筛选阈值（默认 0.65）。前两项只控制混合排名第 7–20 条及扩展候选是否进入 reranker；cue 仍是语义匹配，不要求逐字相同。最终阈值只调整重排准入。调低候选门槛可能增加重排输入，调低最终阈值可能带入更多不相关记忆；分数不是概率。三者都不改变路由是否启动召回、主域限制或冷却。
该区只保留“保存阈值”和“去召回模拟试调”。后者携带当前数值到模拟页，不保存配置或自动运行。点击“运行两档对照”，会用同一句话分别运行已保存阈值与试调阈值；直接进入模拟页时，对照档默认为 0.65。两档各自执行召回，会增加相应模型调用；结果可能受模型波动影响，并非固定候选只换门槛。
模拟页阈值区只试调最终筛选阈值，并保留“保存此阈值”和“返回配置调节”。召回门槛保存按钮不提交长文分段等其他未保存设置；试调本身不会改变实例配置。保存后参数写入实例数据库，用于后续召回，无需重启或重新准备索引。需要恢复默认时分别输入 0.50、0.55、0.65 并保存。旧实例未保存候选门槛时读取默认值但不写库；旧客户端只保存 `direct_threshold` 时，不覆盖已经保存的候选门槛。

可选后台功能选择模型后按各自调度运行；“Event · Arc 归档”只为以后由自动流水线落库的 Event 找已有 Arc，留空就关闭。它使用 Event 标题和正文搜索关键词，不读原话、叙事正文或打标实体，不创建新 Arc。修订箱按程序定时检查已有 Arc，不需要配置模型。Event 整理中留空的角色改为等待 agent，其他后台模型任务留空则关闭。Persona、防撤退还需要打开独立功能开关。TOML 显式启用的扩展
仍由 TOML 管理。Writer 还有独立开关；已有正文的更新／重写先预览再确认保存，空白叙事线明确点击“书写”会生成并保存首篇正文。
外部命令 runner 仍可使用，见 extensions.md。

叙事卷的“从一个主题开始”使用已选择的“叙事卷找材料”模型；未配置时提示选择，不使用隐藏的默认模型。先审阅材料，可只保存空白叙事线，之后再书写。预算、来源校验与操作约定见 [叙事卷说明](narratives.md)。

“打标”在同一次请求里为 Event / Scene 补主域大标签并提取有出处的实体，也负责长 Scene 的 cues 与 passage 绑定；已有主域、正文和 cues 不重写。实体别名只作为建议，具体校验与失效规则见 [实体提取](entity-tagging.md)。文件导入本身无需模型。见 [导入说明](file-imports.md)。
打标、Scene 关系提案和心绪／防撤退评估属于结构化抽取任务；对提供关闭开关的 DeepSeek 与硅基流动上游，请求默认关闭模型思考，避免推理内容占用输出额度并截断 JSON。聊天及其他生成任务不受影响，未知上游也不会收到未经声明的私有参数。

功能开关、名字、上游、模型选择保存在实例 SQLite 配置记录中，保存后供后续请求直接读取；后台模型任务最多约 5 秒重新装配，不需要重启网关。正在执行的有界任务会先结束。TOML 的路径、启动参数和进程环境变量仍在启动时读取，修改它们需要重启；设置页不回写 `.env` 或 YAML。

## 聊天客户端

- Base URL：Serein 网页入口加 `/v1`，例如 `https://你的域名/v1` 或 `http://公网IP:网关端口/v1`。HTTP 公网 IP 示例仍受支持，但不提供传输加密，不建议长期这样传输私人记忆；公网使用推荐 HTTPS 或加密隧道。
- API Key：安装时生成的完整 Gateway Key，输入框不加 `Bearer` 前缀。可从安装输出、`deploy/connection-guide.txt` 或 `deploy/secrets/api-token` 读取。网页登录密码和模型厂商的 Key 都不用于这里。
- Model：从 `GET /v1/models` 拉取聊天模型。`id` 和 `name` 均为“上游名/别名或模型号”，`owned_by` 是上游名称；向量及重排模型不在其中。
- 在客户端添加请求头 `X-Serein-Window-ID`，值为当前会话的独立 ID；同一窗口保持不变，新建窗口换值。客户端支持会话 ID 变量时可使用它。旧客户端的 `X-Ombre-Session-Id` 也可兼容。
- 不填时回退到 `main`，聊天、记忆及已开启的会话功能仍可运行，但这些请求共用轮次、状态与召回冷却，不能识别新窗口。全局填写一个固定请求头也不能区分窗口。开窗续接仍需显式发送 `/resume` 指令。

远程 MCP 的服务器 URL 填 `https://你的域名/serein/mcp`，传输类型选 **Streamable HTTP**。支持 OAuth 的客户端（包括官端自定义 MCP）把身份验证选为 **OAuth**；浏览器打开 Serein 授权页后，手动输入 Gateway Key 并确认。OAuth 需要 HTTPS 域名，同机 localhost 例外；不要把 Key 写进 URL、回调地址或客户端名称。

不支持 OAuth、但支持自定义请求头的客户端仍可使用静态方式：`Authorization: Bearer <Gateway Key>`；专门的 Bearer Token 输入框只填 Key。直接使用 `http://公网IP:网关端口/serein/mcp` 时也只能用静态方式。旧 `/mcp` 路由继续兼容。更换 Gateway Key 会同时撤销旧静态 Key 与已发放的 OAuth 凭据，需要重新授权。

静态 Key 只用于鉴权，不会加密 HTTP 请求；上面的公网 HTTP MCP 示例与聊天 API 有同样的凭据和内容泄露风险。安全建议不改变这些入口的兼容支持，也不放宽 OAuth 的 HTTPS 要求。公开求助时请遮挡真实实例地址、密码和 Key，具体见 [HTTP 兼容与访问风险](interactive-install.md#http-兼容与访问风险)。

网页 **使用说明 → 接入** 提供公网 IP 和域名的连接地址模板。菜单 6 会更换 Key，所有客户端均需同步；查看现有 Key 无需更换。仅连接 MCP 不会让直连其他模型平台的聊天自动经过 Serein 网关。

```json
{
  "model": "provider-a/shared-model",
  "messages": [{"role":"user","content":"上次读书会的安排是什么？"}],
  "stream": true,
  "serein": {"window_id":"book-club-window", "memory":true}
}
```

`serein` 字段可省略：是否召回跟随设置页开关，窗口 ID 可通过请求头传入。
多个上游时必须指定 `model`。只有一个上游时，未指定则使用该上游的可用 `default_model` 或首个聊天模型，不会选择已指定为向量或重排的模型。
聚合的是配置模板中列出的模型，不自动请求服务商账户的完整模型目录。
普通回复、流式文本、工具调用和 usage 会转发。Operit 外部注入块先与真正用户话语分开处理。
召回使用 Scene/Event 混合六个直接候选，加最多一个已确认关系相连的 Scene，共用一次 reranker；最终筛选阈值默认 0.65，可在“配置”调整。最多两卡、选卡后冷却不补位。关系候选不保证入选。

响应头 `X-Serein-Selected-Ids` 表示本次提供给上游的选卡，不能仅凭响应头认定请求成功。
成功结果的 receipt 可在 `/v1/host/deliveries` 查询，`delivery_target=upstream_model`；它不代表用户读过回复。
工具续轮复用注入前缀；失败或未完成的流不写成功 receipt。详见 [聊天网关](chat-gateway.md)。

代理不猜当前聊天窗口，不导入其他客户端会话，也不自动把整份传入历史再次归档。
原文接入仍使用显式 `import-chat` 或 `/api/ingest-raw`，Event 整理由已归档材料生成。

心绪和防撤退共用“心绪/防撤退”模型，开关仍分开。防撤退异步评估后供下一轮提示，带独立窗口冷却。梦境模型选好后可填写主模型 Prompt；开启“主模型读写叙事卷”则由主模型通过 narrative_volume 撰写，自动 Writer 关闭。整理的输入量与长任务超时在“导入”页设置。

公开样例更新为独立合成的 `public-synthetic-v2`；升级后须重新准备路由向量。样例里的 `{user_name}`、`{ai_name}` 在准备时按实例配置展开，修改姓名后下次准备才更新对应向量；不会替换已存记忆的原文姓名。
